Dashboard ini membaca data yang dikirim EA dari VPS. Isi URL Firebase dan token rahasia dulu:

  1. Klik Pengaturan di kanan atas.
  2. Tempel URL Realtime Database (contoh: https://proyek-anda-default-rtdb.firebaseio.com).
  3. Tempel token rahasia yang sama persis dengan yang dipakai di EA.
  4. Klik Tes koneksi, lalu Simpan.
